## Terms
- **Sdui / Sdui app (`apps/sdui-app`)**: school communication app (chat, news, absences, sick notes, digital classbook). Brands named in the PR template: Sdui, PupilConnect, Berlin, Saarland, Untis.
- **Core (`apps/core`, docs name `sduiapp-core`)**: Laravel (PHP) backend and API; `sduiapp-frontend` is the Vue web/Capacitor app docs name.
- **Sdui Meet (`apps/sduiapp-meet`)**: Sdui's fork of Jitsi Meet, used for video calls. **Jitsi** is the open-source video conference software. **git subtree**: git feature that embeds another repo's history in a folder so upstream updates can be merged.
- **IAM / Keycloak / Atlantis Identity**: IAM is the new identity service replacing the legacy Keycloak instance; Atlantis Identity is the SSO section of the admin panel. **Step-up auth**: extra login assurance level (`acr>=2`) required for sensitive features (digital classbook, sick notes, absences, exports). **Univention**: identity vendor for some schools. **TMS**: a platform service (v2) managing organizations and identity providers.
- **MCP (Model Context Protocol)**: a standard for AI assistants to call tools; here `/mcp/chat` on Core. **Seven Assistant**: the in-app AI assistant widget. **Educa / Educa hub**: AI provider (`operations.educaai.de`); **Opus-MT**: open translation models run on-device via ONNX.
- **Holder / Holder portal**: a separate portal for school holders; meaning not stated in the PRs (see Unclear).
- **DS42 / DS42 Dev**: the infrastructure environment ("dev.ds42.cloud"); **mono-main**: the shared Sdui feature environment built from main; **Passport**: OAuth client system in Core.
- **ARC**: Actions Runner Controller (self-hosted GitHub runners on the infra team's cluster); pools `arc-full` / `arc-slim`. **delivery-templates**: shared pipeline templates repo; **delivery.yaml**: per-app delivery config; **gitops** repo `services-ovh-apps`.
- **Playwright / `@smoke` / `@quarantine`**: browser E2E test tool and test tags (`@quarantine` = specs excluded for flakiness).
- **How other teams request things**: the README was not read; the PR template points to a Teams channel "sdui" and a Confluence Deployment Guide (SCTS space) for releases, and PRs need Jira tickets (SC-, INFRA-, PE-, WIZ-) in branch name and title.
