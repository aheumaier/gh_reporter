   **For other teams:** features in Core (News, Chats) that need a holder's schools should call `HolderSchoolsService::schoolIds(holderSchoolId)` and handle `HolderPortalUnavailableException`. ## Terms
- Sdui Core / `apps/core`: the PHP (Laravel) backend of the Sdui app. `apps/sdui-app`: the frontend (Vue, iOS/Android). (Inferred from paths and docs.)
- Holder (Traeger): organisation running several schools; school type `holder`. Holder portal: `apps/holder`, admin app for holders; holder-api: its API.
- Back channel: Core calls the holder portal's API using a Passport client.
- IAM / UMS / TMS / Keycloak: identity systems behind login; step-up auth: re-authentication for sensitive actions. Univention: external identity provider used by some schools.
- Platform (outbound/inbound sync): Core's sync with another Sdui platform; outbound scope limited to school years from 2025.
- vault-proxy: Go service in front of HashiCorp Vault for 2FA/secrets. Vault: secret store.
- delivery / delivery template: shared CI/CD workflow ("delivery: update to template ..."). ARC: GitHub Actions Runner Controller.
- Alloy, Loki: Grafana agent and log store. CH: Swiss (Switzerland) hosts/deployment (ch-fpm-01).
- Lokalise: translation tool. Langfuse: LLM prompt management. Gemma 4: AI model for news generation. educa AI: AI client. Seven Assistant: AI assistant. ai-eval-webhook: package for AI evaluation.
- PUPIL / PupilConnect, Berlin, Saarland, Untis: brands (PR checklist "impact on all brands").
- Release windows (every PR template): regular 17:00-19:00; maintenance/infra/migration 21:00-04:00; announce in Teams beforehand and release as a pair. PR template checklist includes four-eyes review, DB migration process and `pr-review` skill.
