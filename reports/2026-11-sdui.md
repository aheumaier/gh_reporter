# Sdui Meet moved into the monorepo, and the extra login check now asks once a day instead of every six hours

*Sdui app news for November 2026 (2026-11-01 to 2026-11-27).*

**In 30 seconds**
- **Act:** the code of Sdui Meet (video calls) and vault-proxy (part of 2FA) now lives in the monorepo. Open your PRs
  for them there, not in the old repos. If your app calls the Sdui API, check the three changes below.
- **Coming:** a portal for school operators, the extra login check at schools without the authenticator app, and the
  Untis timetable connection moving into the monorepo.
- **Win:** encrypted push notifications work on iOS, the Android keyboard no longer covers the chat input, unread counts
  load faster, and chat translation can now run on the user's device.

The *monorepo* is [sdui-monorepo](https://github.com/7education/sdui-monorepo), the one GitHub repo where all Sdui code is being collected: the app (iOS, Android,
web), *Core* (the backend behind the `/v1` API) and the timetable.

## What you need to do

**Open PRs for Sdui Meet and vault-proxy in the monorepo**
- *Who:* anyone who changes or builds Sdui Meet (Sdui's video calls, built on the open-source Jitsi Meet) or vault-proxy
  (the service in front of the secret store used for two-factor login, 2FA).
- *What:* vault-proxy moved from `sdui-hq/sduiapp-vault-proxy` to the folder `apps/vault-proxy` on 2026-11-02, and
  production has run the monorepo build since 2026-11-03 ([#1653](https://github.com/7education/sdui-monorepo/pull/1653)). Sdui Meet moved to `apps/sduiapp-meet` on
  2026-11-20; its old repo `sdui-hq/sduiapp-meet` is now read-only ([#1785](https://github.com/7education/sdui-monorepo/pull/1785)). (`sdui-hq` is Sdui's GitHub organisation
  from before 7education.) One new rule: when a PR brings in a new Jitsi version, merge it with a merge commit, not
  squash or rebase. That keeps the Jitsi history, so the next Jitsi update can be merged in cleanly.
- *Help:* the Teams channel "sdui".

**Check your calls to the Sdui API**
- *Who:* teams whose own apps or services call Core's `/v1` API.
- *What:* three changes, each live since the day it was merged:
  - *Step-up* is the extra login check: before sensitive pages such as the digital classbook and sick notes, users enter
    their second factor again. It is on at schools that use the authenticator app. Since 2026-11-06 users there are
    asked about once a day instead of every 6 hours, and enter only the second factor instead of logging in again. It
    used to apply only to users with 2FA by e-mail; now it applies to every user at those schools, so your requests for
    any of them can get `401 step_up_required` (the response asks for the second factor, `acr_values: '2'`). Calls with
    a service token (machine to machine, not a user login) are not affected. In the app, opening sick notes now asks for
    step-up and the exports page no longer does ([#1688](https://github.com/7education/sdui-monorepo/pull/1688)).
  - Chat translation (`GET /v1/channels/chats/{chat}/messages/{message}/translate`) returns `422` at schools that turn
    on translation on the device. It means "this school translates in the app, not on the server": treat it as "not
    available here", not as a failure. No school has it on yet ([#1790](https://github.com/7education/sdui-monorepo/pull/1790), 2026-11-26).
  - `GET /v1/find-schools`, the school search before login, no longer lists school operators (*holders*, see Coming up),
    which Core stores like schools. No action unless you need them ([#1747](https://github.com/7education/sdui-monorepo/pull/1747), 2026-11-12).
- *Help:* the Teams channel "sdui", or mention `@7education/sdui` on a PR.

**If you read data from the Classes & Groups service**
- *Who:* teams that use the platform's Classes & Groups service, which gets school years, classes, courses and
  enrollments from Core.
- *What:* since 2026-11-11 Core no longer sends it school years that started before 2025-01-01 (so 2024/25 and older),
  or their classes, courses and enrollments ([#1684](https://github.com/7education/sdui-monorepo/pull/1684), [#1685](https://github.com/7education/sdui-monorepo/pull/1685)). The PRs don't say whether old years that were already
  sent get deleted: ask in the Teams channel "sdui" before you rely on them.

Nothing else needs action from you.

## Where this is going

**Progress:** 2 repos moved into the monorepo this month (vault-proxy, Sdui Meet); 1 is waiting (Untis). The goal is all
code from the old `sdui-hq` repos in one repo: one place to search, one way to review PRs, one set of CI checks.

**AI in the app.** Chat translation can now run on the user's device with open models instead of DeepL or Microsoft: the
text stays on the device and costs nothing per message. Schools turn it on one by one ([#1790](https://github.com/7education/sdui-monorepo/pull/1790)). The Seven Assistant,
the AI helper in the app, can now also search the user's own chats, at schools that turn this on ([#1418](https://github.com/7education/sdui-monorepo/pull/1418), [#1801](https://github.com/7education/sdui-monorepo/pull/1801)).

## Good to know

- **Merged usually means live the same day.** The team deploys `main` by hand almost every workday, and each deploy
  ships everything merged since the last one. This month's main changes went live within an hour of their merge.
- **The `pipeline / …` checks on your PR are a test run** of the shared delivery pipeline from the platform team
  (`@7education/platform`), on the company's own build servers since 2026-11-18. They deploy nothing and don't block
  your merge. If their Core integration checks fail, that is a known pipeline problem, not your code ([#1773](https://github.com/7education/sdui-monorepo/pull/1773), [#1788](https://github.com/7education/sdui-monorepo/pull/1788)).
- **Sdui production is now watched by alerts in Coralogix**, the monitoring tool. Since 2026-11-16, 84 alerts on errors,
  response times, queues, encryption and the servers post to the Slack channel `#coralogix-notifications`. The *Sdui*
  dashboard folder in Coralogix has a dashboard for production health and logins ([change](https://github.com/7education/Infrastructure/commit/6389568), [Infrastructure#84](https://github.com/7education/Infrastructure/pull/84)).
- **App fixes:** encrypted push notifications now work on iOS ([#1661](https://github.com/7education/sdui-monorepo/pull/1661)); on Android the keyboard no longer covers the
  chat input ([#1739](https://github.com/7education/sdui-monorepo/pull/1739), [#1782](https://github.com/7education/sdui-monorepo/pull/1782)); unread counts load faster ([#1791](https://github.com/7education/sdui-monorepo/pull/1791), [#1802](https://github.com/7education/sdui-monorepo/pull/1802)).
